Propuesta de solución tecnológica: Sistema de seguimiento de consultas del Archivo Histórico del CLENA

¿Qué se propone? Descripción general de la solución

1. Se propone desarrollar un programa informático para registrar, organizar y realizar seguimiento a las solicitudes de consulta de documentos del Archivo Histórico del CLENA. El programa tendría una interfaz visual similar a Google Calendar, en la que los encargados puedan consultar las solicitudes registradas, sus fechas y su estado actual.

El sistema permitiría llevar un control organizado de cada solicitud, desde el momento en que se registra hasta que se entrega la información solicitada. De esta manera, se busca reducir los posibles errores y retrasos ocasionados por la falta de seguimiento. Como alternativa, si no se dispone de un sistema informático, se podría utilizar un cuaderno físico con los mismos datos básicos.

2. ¿Para quién? Usuarios que utilizarían la solución

Los usuarios principales serían los encargados de recibir, registrar y gestionar las solicitudes de consulta del Archivo Histórico del CLENA, ya que serían responsables de mantener actualizada la información y verificar el estado de cada solicitud.

Los usuarios secundarios serían las personas que solicitan consultar documentos o recibir copias de archivos. Inicialmente, estas personas no necesitarían utilizar directamente el programa, pues el personal del archivo registraría sus solicitudes. Sin embargo, en una futura versión se podría permitir que los usuarios consultaran el estado de sus solicitudes mediante un mecanismo de consulta autorizado.

3. ¿Qué problema resuelve? Relación directa entre la solución y el problema identificado

La solución busca resolver la falta de un seguimiento fiable de las solicitudes y los documentos consultados en el Archivo Histórico del CLENA.

Al centralizar la información en un solo sistema, se facilitaría la consulta de los registros y se reduciría la posibilidad de olvidar solicitudes, confundir datos o perder el seguimiento de un proceso. Además, la organización por fechas y estados permitiría identificar las solicitudes pendientes, las que se encuentran en proceso y las que ya fueron atendidas.

Esto contribuiría a optimizar el tiempo dedicado a cada consulta y a mejorar la eficiencia y confiabilidad del servicio prestado por el Archivo Histórico.

4. ¿Cómo funcionaría? Descripción básica del funcionamiento

El programa funcionaría mediante un registro individual para cada solicitud. Cuando una persona solicite información o copias de documentos, el encargado ingresaría los datos correspondientes al sistema.

Cada registro incluiría los siguientes campos:

- Número de solicitud: identificador único para distinguir cada consulta.
- Nombre del solicitante: persona que realiza la solicitud.
- Información o documento solicitado: descripción del archivo que se necesita consultar.
- Ubicación del documento: referencia que permita localizarlo dentro del archivo, cuando esta información esté disponible.
- Fecha de solicitud: día en que se registró la consulta.
- Fecha estimada de entrega: fecha aproximada en la que se espera atender la solicitud.
- Tipo de solicitud: consulta presencial, búsqueda de información o solicitud de copias.
- Prioridad: nivel de urgencia, si el archivo considera necesario manejarlo.
- Estado de la solicitud: recibida, en búsqueda, pendiente, lista para entrega o finalizada.
- Observaciones: información adicional relevante para completar el proceso.

Una vez registrada la solicitud, el programa mostraría las consultas en una lista organizada y en una vista de calendario. El encargado podría filtrar los registros por fecha, estado o prioridad, buscar solicitudes por nombre o número de identificación de la solicitud y actualizar su estado a medida que avance el proceso.

Por ejemplo, si una persona solicita una copia de un documento histórico, el encargado registra la solicitud y la fecha estimada de entrega. Posteriormente, cuando el documento sea localizado, actualiza el estado a «Lista para entrega». Finalmente, cuando se entregue la copia, cambia el estado a «Finalizada». Así se mantendría un historial del proceso y se facilitaría el seguimiento de las solicitudes pendientes.

5. ¿Qué tecnología podría utilizarse?

Se podría desarrollar una aplicación web que permita registrar, almacenar, buscar y organizar las solicitudes del Archivo Histórico del CLENA.

La aplicación utilizaría una base de datos para guardar la información de las solicitudes y una interfaz gráfica con una vista de calendario, similar a Google Calendar, que permita visualizar las fechas estimadas de entrega y las consultas pendientes.

Entre sus funcionalidades principales estarían el registro de solicitudes, la búsqueda de información, la clasificación por estados y prioridades, la actualización de los registros y la visualización de las fechas importantes.

El acceso al sistema debería estar restringido al personal autorizado y los datos personales de los solicitantes deberían protegerse. La información sobre los documentos también se manejaría de acuerdo con las normas de acceso y confidencialidad del Archivo Histórico.

No sería necesario desarrollar el programa durante este laboratorio; bastaría con documentar su funcionamiento propuesto y las tecnologías que podrían utilizarse para implementarlo.
