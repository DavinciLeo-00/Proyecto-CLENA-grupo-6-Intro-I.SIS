# Proyecto-CLENA-grupo-6-Intro-I.SIS

## Propósito
Este proyecto tiene como finalidad solucionar la problemática de mantener un seguimiento a solicitudes de archivos historicos ubicados en la Corporación Luis Eduardo Nieto Arteta, más especificamente en el área de "Archivo Historico" utilizando herramientas tecnológicas como una manera de soucionarla.

Este proyecto recibe como nombre Trackhive en relación a la problematica de mantener un debido control de las solicitudes realizadas ante el archivo.
