Sistema de seguimiento de consultas del Archivo Histórico del CLENA

Descripción del proyecto

El proyecto busca mejorar el registro y seguimiento de las solicitudes de consulta de documentos del Archivo Histórico del CLENA, mediante una propuesta de sistema que permita organizar las solicitudes, consultar su estado y controlar las fechas estimadas de entrega.
